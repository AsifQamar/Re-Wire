# ♻️ ReWire

**Doorstep E-Waste Collection with Instant Rewards**

ReWire is a modern web application built with React and Vite. It connects households looking to dispose of their electronic waste with verified, CPCB-authorised recyclers, offering instant rewards based on the weight and category of the items.

## ✨ Features

* **Multi-User Portals:** Dedicated interfaces for both Households (scheduling pickups) and Recyclers (managing incoming requests).
* **Live Reward Calculator:** Dynamically estimates payout amounts based on the user's location, e-waste category, and estimated weight.
* **Recycler Dashboard:** A mock partner dashboard to view KPIs, track incoming pickup requests, and manage subscription plans.
* **Modern UI/UX:** Built with a custom design system featuring CSS variables, smooth scroll animations, and responsive layouts.
* **Fast Routing:** Utilizes `react-router-dom` for seamless, single-page application navigation without page reloads.

## 🛠️ Tech Stack

* **Framework:** [React 18](https://react.dev/)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Routing:** [React Router v6](https://reactrouter.com/)
* **Styling:** Custom CSS with CSS Variables
* **Typography:** Fontshare (Satoshi & Cabinet Grotesk)
